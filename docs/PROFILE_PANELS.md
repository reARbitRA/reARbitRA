# KONKRED — Factory Floor profile panels

This repository’s README uses self-contained SVG panels for the featured repository console and animated activity framing. The actual GitHub contribution data remains a live external chart because GitHub README rendering cannot execute JavaScript or query the GitHub API.

## GitHub rendering limits

- JavaScript, forms, iframes, and most external CSS are not supported in profile README content.
- CSS animation inside SVG images may be reduced or disabled by GitHub’s image proxy and by reduced-motion settings.
- The live contribution chart is provided by `ghchart.rshah.org`; if that service is unavailable, the surrounding Factory Floor activity panel still renders.
- Repository cards link to real repositories and remain accessible without animation.

The palette and motion follow `docs/THEME.md`: warm black, ash neutrals, deep red signal states, hazard strips, scan sweeps, and no rounded panels.
